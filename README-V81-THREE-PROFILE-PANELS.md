- Watching/Reading, Planning, and Global are three equal side-by-side profile panels.
- Each panel shows exactly up to five preview items.
- Each View all control opens a large modal/window instead of expanding or stacking the profile page.
- Planning and Global now have dedicated full-list modals; Watching/Reading keeps its existing full-list modal.
- Existing profile showcase, themes, media tabs, and database schema are unchanged.
- No D1 migration is required.
