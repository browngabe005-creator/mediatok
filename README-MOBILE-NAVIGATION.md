# MediaTok mobile navigation update

This update adds a touch-friendly mobile navigation drawer that exposes the destinations previously only available in the desktop sidebar: Overview, Discover media, Animanga, Films & TV, Books & Comics, Community Forum, Recent Activity, Notifications, My Profile, Customize Profile, Settings, and (for moderators/admins/owners) the Admin Portal.

The drawer is accessible from the **Menu** button in the mobile header, can be dismissed by tapping the backdrop or pressing Escape, respects iPhone safe-area insets, and includes sign-in when logged out. The existing bottom navigation remains focused on the most frequently used media destinations.

Deploy the whole project with `npx wrangler deploy` from this project directory. Test the live site on both iOS Safari and Android Chrome after deployment.
