# MediaTok v78

- Restores the v76 profile layout instead of the v77 compact redesign.
- Removes the Planning box from the profile main content.
- Adds Planning as a dedicated right-side sidebar alongside Collection/Watching and Global.
- Collection/Watching renders the full in-progress list instead of a four-item preview.
- Global recent activity renders the full loaded feed instead of a four-item preview.
- Homepage recommendations are restricted to TV, anime, and manga only.
- No D1 migration is required.
